
# The Mills Korner

Full-stack website and content management platform for The Mills Korner.

## Planned Stack

- React
- Vite
- Python
- Django
- Django REST Framework
- PostgreSQL
- JWT authentication for the custom staff portal
- Django session authentication for Django Admin
